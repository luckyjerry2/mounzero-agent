# 💊 MounZero Agent

AI agent that blocks emotional spending in real time and enforces intentional payments using x402.

---

## 🚀 What it does

MounZero Agent analyzes your spending intent and decides:

- 🚫 BLOCK impulsive/emotional spending
- ✅ APPROVE necessary purchases

If approved, the agent requires a **payment confirmation (x402 flow)** before execution.

---

## 🧠 Key Features

- AI-powered spending intent analysis
- Emotional vs rational purchase classification
- Real-time decision engine (BLOCK / APPROVE)
- Wallet connection (MetaMask)
- x402-style payment flow simulation
- Weekly behavior tracking

---

## 💳 Payment Flow (x402 Concept)

When a purchase is approved:

1. User must connect wallet
2. Agent requires payment (402 Payment Required)
3. User confirms transaction
4. Payment is completed before action

⚠️ This demo simulates x402 payment flow.  
It can be extended to real onchain payments on Base.
